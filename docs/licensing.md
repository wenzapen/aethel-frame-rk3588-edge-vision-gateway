# 授权说明（License）

一句话：**不装任何 license 也能长期用 2 路**；要更多路数，把设备码发给厂商，拿回一个 `license.dat` 文件导入即可。
授权是**离线的**（数字签名 + 设备指纹），设备**不需要联网**、不需要云端激活、不上传任何画面。

---

## 1. 我能用几路？

| 情况 | 可同时运行的路数 | 说明 |
|---|---|---|
| **不装 license（免费档）** | **2 路，永久** | 无倒计时、无水印、功能不裁剪（AI、录像、告警、集成都在） |
| 装有效 license | **4 / 8 / 12 路**（按购买档位） | 16 路不在产品档位内 |
| license 校验失败 | 自动回落到 **2 路** | **不会阻止设备启动**，日志里写明失败原因 |
| license 到期并过了宽限期 | 自动回落到 **2 路** | 已录的录像与历史事件**不受影响**，仍可回放/导出 |

超出上限时的表现：启动或启用通道会返回 `402 license_channel_limit`（带 `used` / `max`）；
配置里写了更多通道也不会报错——启动时按上限截断，续费后重启，被截断的通道自动恢复（配置文件不会被改写）。

## 4. 拿到 license.dat 之后怎么导入

**方式 A：网页导入（推荐，不需要 root）**

1. 「系统 → 授权」→ **导入 License** → 选择 `license.dat`；
2. 页面立刻显示新状态与路数上限；
3. 如果返回里 `restart_required = true`，**重启一次服务**路数才生效：
   `sudo systemctl restart aethel-frame`。

**方式 B：放文件后重启**

```bash
sudo install -m 0644 license.dat /etc/aethel-frame/license.dat
sudo systemctl restart aethel-frame
```

导入后请在「系统 → 授权」确认三件事：状态是 `有效`、路数上限 = 购买档位、到期日正确。

## 5. 状态含义（页面与接口 `GET /api/v1/system/license` 的 `state`）

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| `free` | 免费档 2 路（没装 license） | 无 |
| `valid` | 有效 | 无 |
| `expiring` | 距到期 ≤ 30 天（另有 15 / 7 天提醒） | 联系厂商续费 |
| `grace` | 已过期，宽限期 15 天内，**仍按原路数运行** | 尽快续费，重启后恢复正常期限 |
| `downgraded` | 到期且过宽限，降为 2 路 | 续费并重启 |
| `invalid` | 校验失败（签名不符 / 设备不匹配 / 文件格式或内容被改动） | 见第 7 节排查，必要时重新出证 |

失败原因（`reason` 字段）实际取值：`malformed`（文件不是合法格式）、`unknown_key_id`（签发密钥不在本机内置列表）、
`bad_signature`（签名对不上 ⇒ 文件被改过或传输损坏）、`fingerprint_mismatch`（不是发给这台设备的）。到期不算失败，由 `expiring` / `grace` / `downgraded` 三个状态表示。

## 6. 到期、宽限与更换硬件

- **到期链路**：到期前 30 / 15 / 7 天在页面上提醒 → 到期后进入 **15 天宽限期**（路数不变，让你从容走款）
  → 宽限结束自动降为 **2 路**。整个过程设备不重启、不黑屏、录像继续。
- **续费**：拿同一设备码出新的 `license.dat`，导入并重启即可，历史数据不动。
- **换网卡 / 重装系统**：设备指纹按 **3 项取 2 项一致**判定（芯片序列号、存储标识、系统机器码+网卡地址）。
  换其中一项仍能通过；**同时换两项以上**（例如换了主板/整台设备）需要联系厂商重新出证。
- **license 不能挪到另一台设备**：签名与设备指纹绑定。多站点请分别出证。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 导入后还是 2 路 | 路数上限变化需要**重启服务**（页面会给 `restart_required`） |
| 状态显示 `invalid`，原因 `fingerprint_mismatch` | 设备码与这台机器不匹配（拿错文件 / 换过主板）。重新取一次机器信息发厂商 |
| 原因 `unknown_key_id` | 这份 license 由**厂商的另一把密钥**签发（密钥轮换期间）。联系厂商确认版本与密钥标识 |
| 原因 `bad_signature` / `malformed` | 文件被改过或传输损坏（微信转发常被截断）。请用**原文件**重新导入，或让厂商重发 |
| 升级了软件版本后授权没了 | 授权文件在 `/etc/aethel-frame/`，**升级不会覆盖**。若确实丢失，说明是被手工清理过，重新导入即可 |
| 页面显示正常，但起第 3 路被拒（`402`） | 上限仍是 2 路：确认状态不是 `free`；`license.dat` 是否被放在非默认路径（配置项 `license.file`） |
| 想知道当前跑了几路 | 「系统 → 授权」的"已用路数"，或 `GET /api/v1/system/license` 的 `used_channels` |

> 安全提示：`license.dat` 是**只读凭据**，泄露也不会给攻击者任何权限；但请妥善保管你的**账号密码**与
`/etc/aethel-frame/` 目录（其中含证书私钥与账号库），不要开放 8443 到公网。
