# 授权说明（License）

**不装任何 license 也能长期用 2 路**；要更多路数，把**机器信息**发给厂商，拿回一个 `license.dat` 上传即可。
授权是**离线的**（数字签名 + 设备指纹），设备**不需要联网**、不需要云端激活、不上传任何画面。

---

## 1. 我能用几路？

| 情况 | 可同时运行的路数 | 说明 |
|---|---|---|
| **不装 license（免费档）** | **2 路，永久** | 无倒计时、无水印、功能不裁剪（AI、录像、告警、集成都在） |
| 装有效 license | **按购买的路数**（例如 4 / 8 / 12） | 路数写在授权文件里；配置文件不分档 |
| license 校验失败 | 自动回落到 **2 路** | **不会阻止设备启动**，日志里写明失败原因 |
| license 到期并过了宽限期 | 自动回落到 **2 路** | 已录的录像与历史事件**不受影响**，仍可回放/导出 |

超出上限时的表现：启动或启用通道会返回 `402 license_channel_limit`（带 `used` / `max`）；
配置里写了更多通道也不会报错——启动时按上限截断，**导入更高档授权后点「启动」即恢复**
（配置文件不会被改写，也不需要重启）。

## 3. 获取机器信息（发给厂商）

浏览器打开控制台，进入「系统 → 授权」页，点**下载机器信息**得到 `machine_info.json`
（页面同时显示短码 `AEGIS-XXXX-XXXX-XXXX`，方便沟通时引用）。

`machine_info.json` 里含芯片序列号、存储卡标识等**设备身份**信息，不含画面或业务数据。
把它连同想要的**路数**与**期限**一起发给厂商（联系方式见第 2 节）即可。

---

## 4. 拿到 license.dat 之后怎么上传

厂商把 `license.dat` 发回后，在浏览器上传即可（**不需要 root、不需要重启**）：

1. 「系统 → 授权」→ **导入 License** → 选择厂商发回的 `license.dat`；
2. **即时生效，不需要重启**：页面立刻显示新状态与路数上限；
3. 若新上限比当前运行的路数少，**多出的通道会被自动优雅停用**（从 id 最大的先停，保留 id 最小的那几路），
   任务结果里会列出停用了哪几路；反之（上限变大）只需到「通道」页点「启动」。

> 用哪个用户跑服务，就在哪个用户的控制台里上传。
> 上传后请在「系统 → 授权」确认三件事：状态是 `有效`、路数上限 = 购买的路数、到期日正确。

## 5. 状态含义（页面与接口 `GET /api/v1/system/license` 的 `state`）

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| `free` | 免费档 2 路（没装 license） | 无 |
| `valid` | 有效 | 无 |
| `trial` | **体验授权**有效期内（限期，路数按签发） | 到期自动回落免费档；需要长期使用按第 2 节采购正式授权 |
| `expiring` | 距到期 ≤ 30 天（页面另有倒计时，每天一次提醒；30 / 15 / 7 天为关键节点） | 联系厂商续费 |
| `grace` | 已过期，宽限期 15 天内，**仍按原路数运行** | 尽快续费；导入新授权即恢复 |
| `downgraded` | 到期且过宽限，降为 2 路 | 续费并导入即可恢复（不需重启） |
| `invalid` | 校验失败（签名不符 / 设备不匹配 / 文件格式或内容被改动） | 见第 7 节排查，必要时重新出证 |

失败原因（`reason` 字段）实际取值：`malformed`（文件不是合法格式）、`unknown_key_id`（签发密钥不在本机内置列表）、
`bad_signature`（签名对不上 ⇒ 文件被改过或传输损坏）、`fingerprint_mismatch`（不是发给这台设备的）、
`not_yet_valid`（授权起始时间未到：提前导入下一期授权属正常，到起始时间自动转为有效）。到期不算失败，由 `expiring` / `grace` / `downgraded` 三个状态表示。

## 6. 到期、宽限与更换硬件

- **到期链路**：到期前 **30 天内**页面横幅倒计时（**每天一次**提醒，30 / 15 / 7 天为关键节点） → 到期后进入 **15 天宽限期**（路数不变，预留充足的续费处理时间）
  → 宽限结束自动降为 **2 路**。整个过程设备不重启、不黑屏、录像继续；
  系统每分钟自动复核一次，**降档时只停运行中的多出通道，不删配置、不影响历史数据**。
- **续费**：用同一机器信息出具新的 `license.dat`，**上传即生效（不用重启）**，历史数据不受影响；
  被停用的通道不会自动启动 —— 到「通道」页点「启动」即可。
- **换网卡 / 重装系统**：设备身份按 **3 项取 2 项一致**判定（芯片序列号、存储标识、系统机器码+网卡地址）。
  换其中一项仍能通过；**同时换两项以上**（例如换了主板/整台设备）需要联系厂商重新出证。
- **license 不能用于另一台设备**：签名与设备指纹绑定。多站点请分别出证。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 上传后还是 2 路 | 先看页面与接口返回的 `state` / `reason`：`invalid` 则是文件/设备不对（见下两行）；有效但上限没变，说明这份 license 的路数就是 2 |
| 导入后多出的通道被停了 | 正常行为：新上限比当前运行的路数小。到「通道」页点「启动」需要的那几路（注意总路数不能超限） |
| 状态显示 `invalid`，原因 `fingerprint_mismatch` | 设备码与这台机器不匹配（拿错文件 / 换过主板）。重新取一次机器信息发厂商 |
| 原因 `unknown_key_id` | 这份 license 由**厂商的另一把密钥**签发（密钥轮换期间）。联系厂商确认版本与密钥标识 |
| 原因 `bad_signature` / `malformed` | 文件被改过或传输损坏（微信转发常被截断）。请用**原文件**重新导入，或让厂商重发 |
| 升级了软件版本后授权没了 | 授权文件在你的安装根（默认 `~/aethel-frame/etc/`）里，**升级只替换程序、不会覆盖它**。若确实丢失，说明是被手工清理过，重新导入即可 |
| 导入时返回 500 / 提示写入失败 | `license.file` 指向了当前用户写不了的目录（老配置残留的 `/etc/aethel-frame/`）。改成 `~/aethel-frame/etc/license.dat` 后重新导入（或重启一次让新路径生效） |
| 页面显示正常，但起第 3 路被拒（`402`） | 上限仍是 2 路：确认状态不是 `free`；`license.dat` 是否被放在非默认路径（配置项 `license.file`） |
| 想知道当前跑了几路 | 「系统 → 授权」的"已用路数"，或 `GET /api/v1/system/license` 的 `used_channels` |

> 安全提示：`license.dat` 是**只读凭据**，泄露也不会给攻击者任何权限；但请妥善保管你的**账号密码**与
> 安装根里的 `etc/` 目录（默认 `~/aethel-frame/etc/`，其中含证书私钥与账号库，权限 0600），不要开放 8443 到公网。
