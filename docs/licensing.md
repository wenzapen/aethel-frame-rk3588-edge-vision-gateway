# 授权说明（License）

不安装 license 时，设备提供 **2 路**长期可用；如需更多路数，将**机器信息**提交厂商，获得授权文件 `license.dat` 后导入设备即可。
授权为**离线**机制（数字签名 + 设备指纹），设备**无需联网**、无需云端激活、不上传任何画面。

---

## 1. 路数档位

| 情况 | 可同时运行的路数 | 说明 |
|---|---|---|
| **未导入 license（免费档）** | **2 路，永久** | 无倒计时、无水印、功能完整保留（AI、录像、告警、集成） |
| 导入有效 license | **按购买路数**（例如 4 / 8 / 12） | 路数上限由授权文件决定，配置文件无需按档位区分 |
| license 校验失败 | 自动回落到 **2 路** | **不会阻止设备启动**，日志中记录失败原因 |
| license 到期并过了宽限期 | 自动回落到 **2 路** | 已录的录像与历史事件**不受影响**，仍可回放/导出 |

超出上限时的行为：启动或启用超出上限的通道返回 `402 license_channel_limit`（含 `used` / `max`）；
配置文件中超出上限的通道不会报错，启动时按上限截断；导入更高档授权后，被截断的通道
可直接启动（配置文件不改写，也不需要重启服务）。

## 3. 导出机器信息

浏览器打开控制台，进入「系统 → 授权」页，点击**下载机器信息**得到 `machine_info.json`
（页面同时显示设备短码 `AEGIS-XXXX-XXXX-XXXX`，供沟通时引用）。

`machine_info.json` 仅含芯片序列号、存储介质标识等设备身份信息，不含画面或业务数据。
请将其与所需的**路数**、**期限**一并发给厂商（联系方式见第 2 节）。

---

## 4. 导入授权文件

收到 `license.dat` 后，在浏览器控制台上传即可（无需提权、无需重启服务）：

1. 「系统 → 授权」→ **导入 License** → 选择厂商发回的 `license.dat`；
2. **即时生效，不需要重启**：页面立刻显示新状态与路数上限；
3. 若新上限小于当前运行路数，超出部分会被自动停用（按通道 id 从大到小停止，保留 id 较小的通道），
   停用清单记录在任务结果中；上限变大时，在「通道」页启动所需通道即可。

> 授权文件须与服务运行用户一致，在该用户的控制台页面中上传。
> 上传后请确认：状态为 `有效`、路数上限与购买路数一致、到期日正确。

## 5. 状态含义（页面与接口 `GET /api/v1/system/license` 的 `state`）

| 状态 | 含义 | 建议操作 |
|---|---|---|
| `free` | 免费档 2 路（未安装 license） | 无 |
| `valid` | 有效 | 无 |
| `trial` | **体验授权**有效期内（限期，路数按签发） | 到期自动回落免费档；长期使用需按第 2 节采购正式授权 |
| `expiring` | 距到期 ≤ 30 天（页面另有倒计时，每天一次提醒；30 / 15 / 7 天为关键节点） | 联系厂商续费 |
| `grace` | 已过期，宽限期 15 天内，**仍按原路数运行** | 尽快续费；导入新授权即恢复 |
| `downgraded` | 到期且过宽限，降为 2 路 | 续费并导入即可恢复（不需重启） |
| `invalid` | 校验失败（签名不符 / 设备不匹配 / 文件格式或内容被改动） | 见第 7 节排查，必要时重新出证 |

失败原因（`reason` 字段）实际取值：`malformed`（文件不是合法格式）、`unknown_key_id`（签发密钥不在本机内置列表）、
`bad_signature`（签名不匹配，文件被改过或传输损坏）、`fingerprint_mismatch`（授权绑定的设备与本机不一致）、
`not_yet_valid`（授权生效时间未到；提前导入下一期授权属正常操作，到达起始时间自动转为有效）。到期不属于校验失败，由 `expiring` / `grace` / `downgraded` 三个状态表示。

---

## 6. 到期、宽限与更换硬件

- **到期链路**：到期前 **30 天内**页面横幅提醒（**每天一次**，30 / 15 / 7 天为关键节点） → 到期后进入 **15 天宽限期**（保持原路数，为续费处理提供缓冲）
  → 宽限结束自动降为 **2 路**。整个过程服务不重启，预览与录像不中断；
  系统每分钟自动复核一次，**降档时仅停止超出上限的运行通道，不删除配置、不影响历史数据**。
- **续费**：用同一机器信息出具新的 `license.dat`，**导入即生效（无需重启）**，历史数据不受影响；
  被停用的通道不会自动恢复，需在「通道」页点击「启动」。
- **换网卡 / 重装系统**：设备身份按 **3 项取 2 项一致**判定（芯片序列号、存储标识、系统机器码+网卡地址）。
  换其中一项仍能通过；**同时换两项以上**（例如换了主板/整台设备）需要联系厂商重新出证。
- **license 不能用于另一台设备**：签名与设备指纹绑定。多站点请分别出证。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 导入后仍是 2 路 | 查看页面或接口返回的 `state` / `reason`：`invalid` 表示文件或设备不匹配（见下方两行）；状态有效则说明该授权文件的路数上限即为 2 |
| 导入后多出的通道被停用 | 正常行为：新上限小于当前运行路数。在「通道」页启动所需通道（总路数不可超限） |
| 状态显示 `invalid`，原因 `fingerprint_mismatch` | 设备码与本机不匹配（使用了其他设备的文件或更换过主板）。重新导出一次机器信息发给厂商 |
| 原因 `unknown_key_id` | 这份 license 由**厂商的另一把密钥**签发（密钥轮换期间）。联系厂商确认版本与密钥标识 |
| 原因 `bad_signature` / `malformed` | 文件被改过或传输损坏（传输或文件转发可能截断文件）。请用**原文件**重新导入，或请厂商重发 |
| 升级软件版本后授权失效 | 授权文件位于安装根（默认 `~/aethel-frame/etc/`），**升级只替换程序文件，不会覆盖它**。若确实缺失，可能为手工清理所致，重新导入即可 |
| 导入时返回 500 / 提示写入失败 | `license.file` 指向了当前用户无写入权限的目录（旧配置残留的 `/etc/aethel-frame/`）。修改为 `~/aethel-frame/etc/license.dat` 后重新导入（或重启一次使新路径生效） |
| 页面显示正常，但启用第 3 路被拒（`402`） | 上限仍是 2 路：确认状态不是 `free`；`license.dat` 是否被放在非默认路径（配置项 `license.file`） |
| 查看当前已用路数 | 「系统 → 授权」页面中的已用路数，或 `GET /api/v1/system/license` 的 `used_channels` |

> 安全提示：`license.dat` 与设备指纹绑定，泄露后无法在其他设备使用；需要保密的是**账号密码**与
> 安装根的 `etc/` 目录（默认 `~/aethel-frame/etc/`，含证书私钥与账号库，权限 0600），且不应将 8443 端口暴露至公网。
