# AethelFrame · RK3588 边缘视觉网关

> **AethelFrame（曜帧）** 是运行在 **RK3588** 平台上的多路视频边缘网关：RTSP/ONVIF 摄像机接入 → 硬件解码 →
> NPU 目标检测/行为分析 → 画框叠加 → 告警与录像 → 浏览器控制台。**单机自包含**，不依赖云服务与外部数据库。

本仓库是**发布仓库**：只放交付文档、许可与声明文件；安装包（`.deb`）挂在 **Releases** 页，不进 git。
全部文档均为标准 Markdown（`.md`）文件，**可在浏览器中直接阅读，无需下载**。

---

## 快速部署

```bash
# 1) 到 Releases 页下载最新版的安装包与校验文件
#    aethel-frame_<版本>_arm64.deb   +   aethel-frame_<版本>_arm64.deb.sha256

# 2) 校验文件完整性（校验通过后再安装）
sha256sum -c aethel-frame_<版本>_arm64.deb.sha256

# 3) 安装只读材料到系统（这一步需要一次 sudo）
sudo apt install ./aethel-frame_<版本>_arm64.deb

# 4) 部署到您的用户目录（不使用 sudo，默认安装至 ~/aethel-frame）
aethel-frame-setup

# 5) 启动（用户级服务，日常操作无需提权）
systemctl --user start aethel-frame

# 开机自启（无人值守重启后自动恢复运行）需执行一次：
sudo loginctl enable-linger "$(id -un)"
```

浏览器打开 `https://<设备IP>:8443`，用初始账号 **`admin` / `Aegis@12345`** 登录（首次登录强制修改密码）。
自签证书会触发浏览器告警，确认设备处于本地网络后继续访问。

完整步骤与依赖要求见 [安装指南](docs/install-guide.md)。

## 能力与规格（速览）

| 项 | 说明 |
|---|---|
| 视频接入 | RTSP / ONVIF（含自动搜索取流）/ 本地文件；主 + 子双码流 |
| 解码 / 编码 | RK3588 硬件 VPU 编解码（H.264 / H.265），不经 CPU 软件编解码 |
| AI 推理 | RKNPU2（3 核），内置 **YOLOX-S COCO**（80 类，Apache-2.0）；支持客户自带 YOLO 系列模型（BYOM） |
| 业务分析 | 目标检测 + 跟踪 + 越线/区域等行为规则，检测类别按业务配置；支持 **AI 模板**（保存 / 加载 / 批量下发）复用配置 |
| 输出 | 浏览器 WebRTC（WHEP）预览、子码流转发、告警图片与短视频取证、MP4 录像 |
| 集成 | REST + WebSocket 事件、MQTT / HTTP 外部推送 |
| 授权 | 免费 **2 路**；更多路数由离线签名授权文件按购买数量签发（不依赖云端激活），详见[授权说明](docs/licensing.md) |
| 控制台 | HTTPS 8443，账号分级，支持中英界面 |

实测容量参考（RK3588 8 核 / 16 GB，AI + 录像 + 预览全开）：8 路约占 2.2 核、12 路约占 3.7–4.0 核，
帧率达到设定值、无丢帧。内存建议：2–4 路 ≥ 4 GB，8–12 路 ≥ 8 GB。

## 安全与部署建议

- 控制台端口 **8443 仅开放于内网**。该控制台面向内网使用，不建议直接暴露于公网；如需远程访问，请通过 VPN 或附加认证的反向代理。
- 首次登录后**立即修改默认密码**；安装根下的 `etc/` 目录（默认 `~/aethel-frame/etc/`，含账号库与证书私钥）请妥善保管。
- 建议将录像目录与系统盘分开（默认 `~/aethel-frame/data/recordings`），并按留存天数配置自动清理。
